## Sobre LosPerris

LosPerris es un equipo que crea herramientas para servidores de Minecraft, APIs y proyectos web. Nos gusta que lo que hacemos sea simple de instalar, útil desde el primer día y divertido de usar.

Entre lo que construimos:

- [Plugins para Paper/Spigot](https://github.com/LosPerris/LosPerrisStatsAPI) con rankings, hitos y dashboard web.
- [Addons y extras](https://github.com/LosPerris/LosPerrisExtras): misiones, temporadas, eventos y más.
- [APIs](https://github.com/LosPerris/LosPerrisValorantApi) para consultar datos de Valorant y Twitch.
- [Sitios web](https://github.com/LosPerris/LosPerris) hechos con Astro.

Todo lo que publicamos busca ser accesible y fácil de extender.

## Proyectos

**Minecraft**
- [LosPerrisStatsAPI](https://github.com/LosPerris/LosPerrisStatsAPI): estadísticas, rankings, API HTTP y bot de Discord.
- [LosPerrisExtras](https://github.com/LosPerris/LosPerrisExtras): addon con misiones, evolución, títulos y calendario.

**APIs**
- [LosPerrisValorantApi](https://github.com/LosPerris/LosPerrisValorantApi): consulta tu usuario de Valorant.
- [twitch_api](https://github.com/LosPerris/twitch_api): API de Twitch.

**Webs**
- [LosPerris](https://github.com/LosPerris/LosPerris): nuestro sitio web.
